# 展品纹理图集工作室 · 使用说明

本工具把自制展品纹理打包成**逐块生成 mip、带边缘扩色、旋转 UV 自洽**的纹理图集，
并提供真实像素级的串色（采样污染）检查。本文档先列图形入口，命令行仅作辅助。

## 一、图形入口（主要使用方式）

启动本地服务后用浏览器打开，所有功能都在一个页面内完成：

```bash
npm run dev
# 打开 http://localhost:4173/  （即仓库根目录的 index.html）
```

页面分三栏：

| 区域 | 图形入口 | 能做什么 |
| --- | --- | --- |
| 左栏 · 来源图块 | 「添加 PNG…」「**载入示范素材包**」「恢复示例素材」 | 选择图块、查看尺寸、载入入库的示范包 |
| 左栏 · 构建参数 | padding / 单页上限 / 纹理预算 / 允许旋转下拉框 | 调整后自动重建，图块永不被缩小 |
| 左栏 · 图集层级 | L0…Ln 层级按钮 + 图集画布 | 切换 mip 层级，核心区/扩色带/留白有图例 |
| 中栏 · 三维采样墙 | 守护图集 / 整页滤波（反例）/ 污染差分、Lod 按钮、滚轮缩放 | 近景看细节、远景看 mip 串色 |
| 右栏 · 选中图块 | 图块卡片 + 预览层级滑杆 + 邻域放大 | **预览缩小**，在预览区看图集邻区 |
| 右栏 · 邻区/采样污染 | 三栏拼接、边界剖面、污染表、**异常横幅** | 标出图集邻区和采样污染异常 |
| 右栏 · 诊断输出 | 诊断卡片 + 下载按钮 | 预算、安全 LOD、拆分、警告，可下载 manifest/诊断 |

### 载入示范素材包（图形流程）

1. `npm run dev` 后打开页面；
2. 点击左栏「**载入示范素材包**」；
3. 工具读取 `packs/demo-pack/sources/` 的 7 个自制展品和 `pack-params.json`
   里**保存的打包参数**（缺参数会直接报错，不会用默认值顶替）；
4. 左栏状态条变为「素材包 demo-pack … 运行正常」，右栏顶部出现异常横幅，
   列出检出的图集邻区 / 采样污染异常；
5. 点击任意图块卡片，右栏「图集采样（缩小）」区可用滑杆逐级预览，
   三栏拼接的第一栏就是该图块的**图集邻区**，第三栏放大采样污染；
6. 想回到内置示例，点「恢复示例素材」。手动改任一构建参数后，状态条会如实
   变为自定义构建，不再标注为原始素材包。

## 二、自制测试展品（已入库）

来源生成器：`scripts/generate-cases.mjs`，纯确定性像素绘制，无外部美术资源。

| 图块 | 长宽比 | 检验目标 |
| --- | --- | --- |
| `abut-blocks` | 1:1 | 紧邻高对比色块（红/青、黄/蓝）与内部 1px 接缝 |
| `hairline` | 1:2 | 不透明主体内透明 1px 竖缝、透明外沿细边 |
| `ribbon` | 3.3:1 | 超宽素材，颜色延伸到最后一个像素 |
| `pole` | 1:5 | 细长素材，长边透明缺口，深层 mip 压测 |
| `ring` | 1:1 | 饱和圆盘内透明细环，检验透明区扩色来源 |
| `chip` | 1:1 | 最小图块 + 1px 描边，压测安全 LOD 下限 |
| `letterbox` | 1.75:1 | 四周 1px 透明信箱边 + 对角透明切线 |

## 三、命令行（仅辅助图形界面）

命令行只负责**生成、重建、核验**，日常判断串色仍以图形页面为准。

```bash
npm run assets        # 重建内置 6 个示例来源（配方冻结，像素与入库一致）
npm run cases         # 仅重建 7 个自制展品到 assets/cases/
npm run pack          # 重建来源并整体生成 packs/demo-pack 示范素材包
npm run rebuild-pack  # 读回保存参数，离线重建并逐项核验（不一致即非零退出）
npm test              # 运行 23 个自动化测试（含素材包约定与图形载入流程）
npm run build         # 用内置示例构建 dist/（旧的命令行图集导出）
```

### 示范素材包目录 `packs/demo-pack/`

- `sources/`：自制展品 PNG + `sources.json`（配方、调色板、检验目标、哈希）
- `atlas/`：守护链逐级贴图 `guarded_p0_l*.png`、反例 `naive_p0_l*.png`、`manifest.json`
- `scenes/`：近景 L0 与远景 L2 墙渲染（守护链 / 整页滤波反例各一张）
- `mip-edges/`：每个图块 L0/L1/L2 核心+扩色环放大条带（左守护、右反例）
- `pack-params.json`：打包参数与来源哈希，重建时逐字读回
- `evidence.json`：mip 边缘与采样颜色的逐探针 RGBA 数值和判定
- `README.md`：包内说明

## 四、判定约定（执行证据见 evidence.json）

- 守护链内部不透明探针与图块**自身补丁**重采样结果的 RGB 差 ≤ 2/255；
- 整页滤波反例在边缘探针上的预乘色差 > 8 即标记为采样污染；
- `npm run rebuild-pack` 会重算这些数值并与存档比对，任何篡改或缺文件都会失败；
- 守护链通过、反例污染必须真实存在——默认值无法伪造这两条证据。
